# Format commit:
# type(scope): Mô tả ngắn

# Types:
# feat     - Thêm tính năng mới
# fix      - Sửa lỗi
# refactor - Tối ưu code
# docs     - Cập nhật tài liệu
# style    - Định dạng code
# test     - Thêm hoặc cập nhật test

# Example:
# feat(login): Thêm tính năng Đăng nhập
# fix(cart): Sửa lỗi null pointer trong cart
